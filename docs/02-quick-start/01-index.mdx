This is a quick start guide to get you up and running with Docstra in 5 minutes.

## Installation

```bash
npm install docstra
```

```jsx
import { DocstraProvider } from 'docstra';

function App({ Component, pageProps }) {
    return (
        <DocstraProvider>
            <Component {...pageProps} />
        </DocstraProvider>
    );
}

export default App;
```
